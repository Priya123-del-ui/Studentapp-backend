Installation and Setup Guide:

This guide will help you set up and run the StudentApp backend project locally.

Prerequisites:
- Node.js (v14 or higher recommended)
- npm (Node Package Manager, usually comes with Node.js)
- MongoDB (running instance, local or remote)
- Git

Step 1: Clone the repository
Open your terminal or command prompt and clone the project repository:
git clone [repository_url]
cd StudentApp-backend

Step 2: Install dependencies
Navigate to the project directory and install all required Node.js packages:
npm install

Step 3: Configure Environment Variables
Create a `.env` file in the root directory of the project. You can use `.env.example` as a template.
Example `.env` file:
NODE_ENV=development
PORT=5000
MONGO_URI=mongodb://localhost:27017/studentapp
JWT_SECRET=supersecretjwtkey
JWT_EXPIRES_IN=1h
JWT_REFRESH_SECRET=anothersupersecretjwtkey
JWT_REFRESH_EXPIRES_IN=7d
LOG_LEVEL=info # debug, info, warn, error

Ensure you replace placeholder values (like `JWT_SECRET`, `MONGO_URI`) with your actual configuration.

Step 4: Run Database Migrations (if any)
If there are database migrations set up (e.g., using `migrate-mongo`), run them to set up your database schema.
Refer to `migrate-mongo-config.js` and any migration scripts in the `migrations/` folder.
(Example command, may vary based on actual setup):
npm run migrate up

Step 5: Start the Development Server
You can start the server in development mode:
npm run dev
The server should start on the port specified in your `.env` file (e.g., http://localhost:5000).

Step 6: Run Tests (Optional)
To run the project's tests:
npm test

Build for Production (Optional):
To build the project for production:
npm run build
To start the production build:
npm start

Troubleshooting:
- If you encounter issues with MongoDB connection, ensure your MongoDB instance is running and `MONGO_URI` is correct.
- For missing dependencies, try `npm install` again.
- Check console logs for error messages if the server fails to start.
